# Personal Finance Tracker

A Java-based desktop application designed to help users manage their personal finances by recording and organizing income and expenses. The application uses Java Swing for its graphical user interface and MySQL for database storage.

## Overview

The Personal Finance Tracker provides a simple interface for maintaining financial records and keeping track of personal transactions. It demonstrates the use of Java programming, GUI development, database connectivity, and CRUD operations.

## Features

- **Income and Expense Management:** Record and organize financial transactions.
- **Database Integration:** Store financial records in a MySQL database.
- **CRUD Operations:** Create, read, update, and delete financial records.
- **Graphical User Interface:** Interactive desktop interface developed using Java Swing.
- **Persistent Storage:** Retain transaction records in the database.

## Technologies Used

- **Language:** Java
- **GUI:** Java Swing
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **IDE:** IntelliJ IDEA

## Prerequisites

Before running the application, ensure you have:

- Java Development Kit (JDK) installed
- MySQL Server installed and running
- IntelliJ IDEA or another Java IDE
- MySQL JDBC driver configured in the project

## Installation and Setup

### 1. Clone the repository

git clone https://github.com/Soham2024-developer/Personal-Finance-Tracker.git

### 2. Open the project

Open the cloned project folder in IntelliJ IDEA and configure the JDK and required dependencies.

### 3. Configure the database

Create a MySQL database for the application.

CREATE DATABASE personal_finance_tracker;

Create the required tables according to your application's database schema.

### 4. Configure database connectivity

Update the JDBC connection URL, username, and password in your application's configuration.

### 5. Run the application

Run the main Java class from IntelliJ IDEA after configuring the database and JDBC driver.
